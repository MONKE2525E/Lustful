# L0602: this type form is not supported yet

<!-- rustc-wrong: pass -->

Some type forms have AST shapes but no checker support yet: qualified
and variadic function pointers, and `impl Trait` in some positions.
(Plain function pointer types, tuples, arrays, slices, and
non-generic `type` aliases are supported.) The message names the form.
Rewrite it with a named struct or another supported type. Rust accepts
the wrong example; lust does not.

## Wrong

```rust
fn call(f: extern "C" fn() -> i32) -> i32 {
    f()
}

extern "C" fn seven() -> i32 {
    7
}

fn main() {
    println!("{}", call(seven));
}
```

## Fixed

```rust
fn call(f: fn() -> i32) -> i32 {
    f()
}

fn seven() -> i32 {
    7
}

fn main() {
    println!("{}", call(seven));
}
```
