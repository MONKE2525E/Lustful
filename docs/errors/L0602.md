# L0602: this type form is not supported yet

<!-- rustc-wrong: pass -->

The AST has shapes for tuple, array, slice, function pointer, `dyn`,
`impl Trait`, raw pointer, never, and inferred types, and for `type`
aliases, but the checker does not handle them yet. The message names the
form. Rewrite it with a named struct or another supported type. Rust
accepts the wrong example; lust does not.

## Wrong

```rust
fn first(p: (i64, i64)) -> i64 {
    p.0
}

fn main() {
    println!("{}", first((1, 2)));
}
```

## Fixed

```rust
struct Pair {
    a: i64,
    b: i64,
}

fn first(p: Pair) -> i64 {
    p.a
}

fn main() {
    println!("{}", first(Pair { a: 1, b: 2 }));
}
```
