# L0602: this type form is not supported yet

<!-- rustc-wrong: pass -->

Some type forms have AST shapes but no checker support yet: function
pointer, `dyn`, `impl Trait`, raw pointer, and inferred types. (Tuples,
arrays, slices, and non-generic `type` aliases are supported.) The
message names the form. Rewrite it with a named struct or another
supported type. Rust accepts the wrong example; lust does not.

## Wrong

```rust
fn apply(f: fn(i64) -> i64, x: i64) -> i64 {
    f(x)
}

fn inc(x: i64) -> i64 {
    x + 1
}

fn main() {
    println!("{}", apply(inc, 2));
}
```

## Fixed

```rust
fn inc(x: i64) -> i64 {
    x + 1
}

fn main() {
    println!("{}", inc(2));
}
```
