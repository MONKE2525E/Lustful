# L0602: this type form is not supported yet

<!-- rustc-wrong: pass -->

Some type forms have AST shapes but no checker support yet: function
pointer, `dyn`, `impl Trait`, raw pointer, and inferred types, and
`type` aliases. The message names the form. Rewrite it with a named
struct or another supported type. Rust accepts the wrong example;
lust does not.

## Wrong

```rust
type Pair = (i64, i64);

fn first(p: Pair) -> i64 {
    p.0
}

fn main() {
    println!("{}", first((1, 2)));
}
```

## Fixed

```rust
fn first(p: (i64, i64)) -> i64 {
    p.0
}

fn main() {
    println!("{}", first((1, 2)));
}
```
