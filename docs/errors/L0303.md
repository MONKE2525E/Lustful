# L0303: conflicting borrows

A value cannot be changed through a `&mut` reference while a shared `&` reference to it
is still in use, and it cannot be read through `&` while a `&mut` is still in use.
Finish using the first reference before you take or use the other one. Copying a small
value out first often removes the conflict.

## Wrong

```rust
fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];
    v.push(4);
    println!("{}", first);
}
```

## Fixed

```rust
fn main() {
    let mut v = vec![1, 2, 3];
    let first = v[0];
    v.push(4);
    println!("{}", first);
}
```
