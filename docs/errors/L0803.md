# L0803: include file not found

`include!`, `include_str!`, and `include_bytes!` read a file at
expansion time, relative to the file that holds the call. The file
could not be read.

## Wrong

```rust
fn main() {
    let _s = include_str!("no-such-file-12345.txt");
}
```

## Fixed

```rust
fn main() {
    let _s = "text from the file";
    println!("ok");
}
```
