# L0731: explicit lifetime arguments on a fn

A turbofish named a lifetime (`f::<'static>(..)`). Rust rejects this
whenever the fn has a late-bound lifetime (E0794), the common case; lust
rejects it in every case. Remove the lifetime argument: Rust infers it.

## Wrong

```rust
fn first<'a>(x: &'a str) -> &'a str {
    x
}

fn main() {
    println!("{}", first::<'static>("a"));
}
```

## Fixed

```rust
fn first<'a>(x: &'a str) -> &'a str {
    x
}

fn main() {
    println!("{}", first("a"));
}
```
