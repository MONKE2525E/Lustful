# L0721: this method or receiver form is not supported yet

<!-- rustc-wrong: pass -->

Turbofish on method calls (`x.method::<T>()`) and typed receivers
(`self: Box<Self>`) have AST shapes but no checker support yet. Remove the
turbofish, or take `self`, `&self`, or `&mut self`. Rust accepts the wrong
example; lust does not.

## Wrong

```rust
struct S;

impl S {
    fn get(self: Box<Self>) -> i64 {
        1
    }
}

fn main() {
    let b = Box::new(S);
    println!("{}", b.get());
}
```

## Fixed

```rust
struct S;

impl S {
    fn get(self) -> i64 {
        1
    }
}

fn main() {
    let s = S;
    println!("{}", s.get());
}
```
