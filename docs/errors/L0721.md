# L0721: this method form is not supported yet

Turbofish (`x.method::<T>()`) works on generic methods. On a
method that is not generic it has nothing to name, so lust
reports it with this code. Remove the turbofish.

## Wrong

```rust
struct S;

impl S {
    fn get(&self) -> i64 {
        1
    }
}

fn main() {
    println!("{}", S.get::<i64>());
}
```

## Fixed

```rust
struct S;

impl S {
    fn get(&self) -> i64 {
        1
    }
}

fn main() {
    println!("{}", S.get());
}
```
