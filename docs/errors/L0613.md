# L0613: an impl parameter is not known from the trait inputs

This impl has a generic parameter that its trait reference and
associated equalities do not fix. A use site has no place to
write it, so lust reports it instead of searching. Rewrite the
impl so the parameter follows from the trait inputs or from an
associated equality.

## Wrong

```rust
trait A {
    type Item;
}

trait Tr {
    fn v() -> u8 {
        5
    }
}

impl<T, U> Tr for T where T: A<Item = U> {}

fn check<T: Tr>() -> u8 {
    T::v()
}

fn main() {
    println!("{}", check::<u8>());
}
```

## Fixed

```rust
trait A {
    type Item;
}

trait Tr {
    fn v() -> u8 {
        5
    }
}

impl<T, U> Tr for T where T: A<Item = U> {}

impl A for u8 {
    type Item = u16;
}

fn check<T: Tr>() -> u8 {
    T::v()
}

fn main() {
    println!("{}", check::<u8>());
}
```
