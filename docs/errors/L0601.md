# L0601: type alias cycle

A type alias names itself, directly or through other aliases. Break the
cycle: point one alias at a real type.

## Wrong

```rust
type A = B;
type B = A;

fn get(x: A) -> i64 {
    x
}

fn main() {
    println!("{}", get(1));
}
```

## Fixed

```rust
type A = i64;

fn get(x: A) -> i64 {
    x
}

fn main() {
    println!("{}", get(1));
}
```
