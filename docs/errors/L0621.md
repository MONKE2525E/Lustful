# L0621: associated consts are not supported yet

<!-- rustc-wrong: pass -->

Associated types, bindings such as `Item = u8`, and qualified
paths such as `<T as Trait>::Item` work. Associated consts do
not yet: their values need the const evaluator's value path.
Use a plain function or a free name instead. Rust accepts the
wrong example; lust does not.

## Wrong

```rust
struct S;

impl S {
    const ONE: i64 = 1;
}

fn main() {
    println!("{}", S::ONE);
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
