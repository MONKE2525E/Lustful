# L0621: associated items are not supported yet

<!-- rustc-wrong: pass -->

Associated consts and types, associated bindings such as `Item = u8`, and
qualified paths such as `<T as Trait>::Item` have AST shapes but no parser
or checker yet. Use a plain function or a free name instead. Rust accepts
the wrong example; lust does not.

## Wrong

```rust
struct S;

impl S {
    const ONE: i64 = 1;
}

fn main() {
    println!("{}", S::ONE);
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
