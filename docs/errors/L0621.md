# L0621: this associated item form is not supported yet

Some associated item forms have no checker support yet:
associated types in inherent impls, generic associated types,
associated binding constraints in some positions, and qualified
paths with more than one segment after the trait. Associated
types in traits, plain associated bindings such as `Item = u8`,
single-segment qualified paths, and scalar associated consts in
inherent impls are supported.

## Wrong

```rust
struct S;

impl S {
    type Item = i64;
}

fn main() {
    println!("x");
}
```

## Fixed

```rust
struct S;

type Item = i64;

fn main() {
    let x: Item = 1;
    println!("{}", x);
}
```
