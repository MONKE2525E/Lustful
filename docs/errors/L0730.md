# L0730: overflow while adding drop-check rules

Before a value is dropped, the borrow checker lists every type its
drop may touch: the type's fields, their fields, and so on. When a
type names itself again with larger type arguments (polymorphic
recursion, such as `Grow<T>` holding a `Grow<(T, T)>`), the list
never ends. rustc stops at its recursion limit (128) and rejects the
body (E0320). The check runs on every parameter, binding, return
value, and temporary of a function, also in a generic function that
is never called. It stops at a reference, a raw pointer, a fn
pointer, a `dyn` type, and `ManuallyDrop`.

## Wrong

```rust
struct Grow<T> {
    v: T,
    g: Option<Box<Grow<(T, T)>>>,
}

fn main() {
    let g: Grow<u8> = Grow { v: 1, g: None };
    println!("{}", g.v);
}
```

## Fixed

```rust
struct Grow<T> {
    v: T,
    g: Option<Box<Grow<T>>>,
}

fn main() {
    let g: Grow<u8> = Grow { v: 1, g: None };
    println!("{}", g.v);
}
```
