# L0306: value does not live long enough

A reference is still in use after the value it points to is dropped at the end of its
scope. A temporary value has the same problem: it is dropped at the end of the
statement. Declare the value in an outer scope, or store a temporary in a `let`
variable first so it lives long enough.

## Wrong

```rust
fn main() {
    let r;
    {
        let x = String::from("short");
        r = &x;
    }
    println!("{}", r);
}
```

## Fixed

```rust
fn main() {
    let x = String::from("long");
    let r = &x;
    println!("{}", r);
}
```
