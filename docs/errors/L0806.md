# L0806: this macro call does not fit

No rule of the macro accepts this input, or a built-in macro got an
argument of the wrong shape (including `compile_error!` firing and
`env!` on a variable that is not set). It is also the error when a
fragment such as `$e:expr` began to parse and failed: as in rustc,
later rules are not tried then.

## Wrong

```rust
macro_rules! m {
    (yes) => {
        1
    };
}

fn main() {
    println!("{}", m!(no));
}
```

## Fixed

```rust
macro_rules! m {
    (yes) => {
        1
    };
}

fn main() {
    println!("{}", m!(yes));
}
```
