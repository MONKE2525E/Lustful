# L0806: this macro call does not fit

No rule of the macro accepts this input, or a built-in macro got an
argument of the wrong shape (including `compile_error!` firing and
`env!` on a variable that is not set).

## Wrong

```rust
macro_rules! m {
    (yes) => {
        1
    };
}

fn main() {
    println!("{}", m!(no));
}
```

## Fixed

```rust
macro_rules! m {
    (yes) => {
        1
    };
}

fn main() {
    println!("{}", m!(yes));
}
```
