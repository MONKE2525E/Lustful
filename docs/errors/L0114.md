# L0114: value is not callable

Only named functions, methods, variants, and a few built-in constructors can be called.
Closures and function values are not supported yet, and a local variable cannot be
called. Call a named function instead.

## Wrong

```rust
fn main() {
    let x = 5;
    let y = x();
    println!("{}", y);
}
```

## Fixed

```rust
fn main() {
    let x = 5;
    let y = x;
    println!("{}", y);
}
```
