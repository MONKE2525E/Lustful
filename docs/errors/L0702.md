# L0702: this dyn form is not supported yet

<!-- rustc-wrong: pass -->

lust builds vtables for traits defined in the crate, used as
`&dyn Trait` or `&mut dyn Trait`, with optional `Send` and `Sync`
bounds. Other dyn forms give this code: a std trait as the
principal (`dyn Display`, `dyn Fn(u8)`), a dyn type with no
principal trait, traits with associated types, std supertraits
other than `Debug` and `Display`, higher-ranked dyn types, dyn
types in const and static items, and
traits with a method bounded by `where Self: Send` (rustc allows
that bound; lust does not check it at dyn calls yet).
`Box<dyn Trait>` and the other smart pointers come with std. Rust
accepts the wrong example; lust does not.

## Wrong

```rust
fn show(x: &dyn std::fmt::Display) {
    println!("{}", x);
}

fn main() {
    show(&3);
}
```

## Fixed

```rust
trait Show {
    fn show(&self) -> String;
}

impl Show for i32 {
    fn show(&self) -> String {
        format!("{}", self)
    }
}

fn show(x: &dyn Show) {
    println!("{}", x.show());
}

fn main() {
    show(&3);
}
```
