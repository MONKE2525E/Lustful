# L0102: type not found

A type name is used, but the file does not define a struct or enum with that name, and it
is not a supported built-in type. Define the type, or fix the name. `Self` also gives this
error outside an impl block.

## Wrong

```rust
fn id(x: Nope) -> i64 {
    1
}

fn main() {
    println!("{}", id(3));
}
```

## Fixed

```rust
fn id(x: i64) -> i64 {
    x
}

fn main() {
    println!("{}", id(3));
}
```
