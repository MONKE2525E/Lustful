# L0542: invalid atomic memory ordering

An atomic operation names an ordering it does not allow, written as the
`Ordering` variant itself: a `load` with `Release` or `AcqRel`, a
`store` with `Acquire` or `AcqRel`, a `fence` or `compiler_fence` with
`Relaxed`, or a `compare_exchange` failure ordering of `Release` or
`AcqRel`. Rust rejects this code with the deny-level
`invalid_atomic_ordering` lint, so lust rejects it too. An ordering
chosen at run time panics instead, with std's message.

## Wrong

```rust
use std::sync::atomic::{AtomicUsize, Ordering};

fn main() {
    let hits = AtomicUsize::new(0);
    println!("{}", hits.load(Ordering::Release));
}
```

## Fixed

```rust
use std::sync::atomic::{AtomicUsize, Ordering};

fn main() {
    let hits = AtomicUsize::new(0);
    println!("{}", hits.load(Ordering::Acquire));
}
```
