# L0612: no impl of the trait for this type

A bound or call needs a trait impl that does not exist for
this type. Selection matched the whole trait reference and
found no candidate. Add the impl, or change the bound.

## Wrong

```rust
trait Tr {
    fn v(&self) -> u8;
}

struct S;

fn call<T: Tr>(v: &T) -> u8 {
    v.v()
}

fn main() {
    println!("{}", call(&S));
}
```

## Fixed

```rust
trait Tr {
    fn v(&self) -> u8;
}

struct S;

impl Tr for S {
    fn v(&self) -> u8 {
        1
    }
}

fn call<T: Tr>(v: &T) -> u8 {
    v.v()
}

fn main() {
    println!("{}", call(&S));
}
```
