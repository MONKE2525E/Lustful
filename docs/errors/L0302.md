# L0302: cannot assign to an immutable variable

Variables are immutable by default. A variable that is assigned more than once, or
whose fields are assigned, must be declared with `let mut`.

## Wrong

```rust
fn main() {
    let x = 5;
    x = 6;
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let mut x = 5;
    x = 6;
    println!("{}", x);
}
```
