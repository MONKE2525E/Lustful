# L0104: no such method, variant, or associated function

The name after `.` or `::` does not exist on this type. For built-in types such as Vec,
String, and Option, lust supports a small set of std methods. Run
`lust capabilities --json` to list them.

## Wrong

```rust
fn main() {
    let v: Vec<i64> = Vec::new();
    println!("{}", v.nope());
}
```

## Fixed

```rust
fn main() {
    let v: Vec<i64> = Vec::new();
    println!("{}", v.len());
}
```
