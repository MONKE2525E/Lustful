# L0307: cannot return a reference to a local value

Local variables are dropped when the function returns, so a reference to one would
dangle. Return an owned value instead, for example `String` instead of `&str`.

## Wrong

```rust
fn dangle(n: &i64) -> &String {
    let s = format!("{}", n);
    &s
}

fn main() {
    println!("{}", dangle(&1));
}
```

## Fixed

```rust
fn show(n: &i64) -> String {
    format!("{}", n)
}

fn main() {
    println!("{}", show(&1));
}
```
