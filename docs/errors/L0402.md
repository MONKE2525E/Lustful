# L0402: unsupported attribute

<!-- rustc-wrong: pass -->

Only a few attributes exist in the subset: `#[derive(...)]`, `#[test]`, and the lint
attributes `#[allow(...)]`, `#[warn(...)]`, and `#[deny(...)]` (which have no effect).
Remove the attribute. Rust accepts the wrong example; lust does not.

## Wrong

```rust
#[inline]
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
