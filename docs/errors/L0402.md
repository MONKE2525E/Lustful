# L0402: unsupported attribute

Lust does not know this attribute name at all. Only a few attributes exist in
the subset: `#[derive(...)]`, `#[test]`, and the lint attributes
`#[allow(...)]`, `#[warn(...)]`, and `#[deny(...)]` (which have no effect).
A known Rust attribute that lust does not handle yet, such as `#[inline]` or
`#[cfg(...)]`, gives L0522 instead. Remove the attribute, or fix its name.

## Wrong

```rust
#[frobnicate]
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
