# L0543: drop of a ManuallyDrop does nothing

`std::mem::drop(m)` with `m` a `ManuallyDrop<T>` moves `m` and
forgets it: `ManuallyDrop` never drops the value inside. rustc denies
this by default (lint `undropped_manually_drops`), so the call is an
error unless an `#[allow]`, `#[warn]`, or `#[expect]` of the lint
covers it. lust reads these levels on the statement and on the
enclosing fn. When the inner type is `Copy`, rustc warns about a
`Copy` drop instead, except when the call is a whole match arm body
whose argument may have side effects.

## Wrong

```rust
use std::mem::ManuallyDrop;

fn main() {
    let m = ManuallyDrop::new(String::from("x"));
    drop(m);
    println!("done");
}
```

## Fixed

```rust
use std::mem::ManuallyDrop;

fn main() {
    let m = ManuallyDrop::new(String::from("x"));
    drop(ManuallyDrop::into_inner(m));
    println!("done");
}
```
