# L0112: trait is not implemented

An operation needs a trait that the type does not have. Equality with `==` needs
`PartialEq`, printing with `{:?}` needs `Debug`, and copying needs `Copy` (with
`Clone`). Add the name to the `#[derive(...)]` list on the type. The `?`
operator also gives this code: it needs an `Option` or `Result` operand, a
matching enclosing return type, and a `From` impl that converts the error.

## Wrong

```rust
struct P {
    x: i64,
}

fn main() {
    let a = P { x: 1 };
    let b = P { x: 1 };
    println!("{}", a == b);
}
```

## Fixed

```rust
#[derive(PartialEq)]
struct P {
    x: i64,
}

fn main() {
    let a = P { x: 1 };
    let b = P { x: 1 };
    println!("{}", a == b);
}
```
