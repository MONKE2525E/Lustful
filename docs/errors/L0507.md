# L0507: ambiguous name from glob imports

Two glob imports bring different items with the same name, and the code
uses that name. The collision is an error only at the use. Import the
item you mean explicitly: an explicit import wins over globs.

## Wrong

```rust
mod a {
    pub fn value() -> i64 {
        1
    }
}

mod b {
    pub fn value() -> i64 {
        2
    }
}

use a::*;
use b::*;

fn main() {
    println!("{}", value());
}
```

## Fixed

```rust
mod a {
    pub fn value() -> i64 {
        1
    }
}

mod b {
    pub fn value() -> i64 {
        2
    }
}

use a::*;
use b::*;
use a::value;

fn main() {
    println!("{}", value());
}
```
