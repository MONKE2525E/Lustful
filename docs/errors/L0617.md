# L0617: a type here needs an outlives bound that does not hold

A reference type `&'a T` is well-formed only when `T` outlives
`'a`, and `&'a &'b X` only when `'b` outlives `'a`. A struct that
holds `&'a T` puts the same requirement on each use. A function
may assume these requirements for the types of its parameters and
its return type (implied bounds), and an impl for the types in
its header. The types in a where clause, a trait bound, an
associated type binding, an `impl Trait` argument, an associated
type value, a struct's where clause, or a `let` annotation get no
such help (rustc E0309, E0310, E0491). lust does not take a
written `T: 'a` bound yet, so take a parameter of the type that
needs the bound, or bound the type parameter by `'static`.

## Wrong

```rust
fn first<'a, T: Copy, I: IntoIterator<Item = &'a T>>(i: I) -> Option<T> {
    i.into_iter().next().copied()
}

fn main() {
    let v = vec![1, 2];
    println!("{:?}", first(&v));
}
```

## Fixed

```rust
fn first<'a, T: Copy, I: IntoIterator<Item = &'a T>>(_s: &'a [T], i: I) -> Option<T> {
    i.into_iter().next().copied()
}

fn main() {
    let v = vec![1, 2];
    println!("{:?}", first(&v, &v));
}
```
