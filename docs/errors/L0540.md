# L0540: arithmetic operation will overflow

The operands are known at compile time, and the result does not fit in
the type. Rust rejects this code with the deny-level
`arithmetic_overflow` lint, so lust rejects it too. This covers `+`, `-`,
`*`, negation of the minimum value, and shifts by more than the type
width, when the operands are literals or locals with a known value. If
the wrap is intended, write it with a `wrapping_*` operation, or allow
the lint with `#[allow(arithmetic_overflow)]`.

## Wrong

```rust
fn main() {
    let a: u8 = 255;
    println!("{}", a + 1);
}
```

## Fixed

```rust
fn main() {
    let a: u8 = 255;
    println!("{}", a.wrapping_add(1));
}
```
