# L0101: name not found

A variable, function, or type name is used, but no definition with that name is in scope.
Check the spelling. Functions and types must be defined in the same file, because lust
has no modules yet.

## Wrong

```rust
fn main() {
    println!("{}", missing);
}
```

## Fixed

```rust
fn main() {
    let missing = 1;
    println!("{}", missing);
}
```
