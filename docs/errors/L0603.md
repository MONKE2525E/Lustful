# L0603: the `!` type is unstable outside a function return type

Stable Rust takes a written `!` (the never type) only as the whole
return type after `->`: of a fn, a method, a closure, or a fn pointer.
Every other position (a generic argument, a field, a parameter, a `let`
type, a type alias, `-> Option<!>`, `Fn() -> !` sugar) needs the
unstable `never_type` feature, and rustc rejects it (E0658). Lust does
the same. Use an empty enum or `std::convert::Infallible` instead.

## Wrong

```rust
fn main() {
    let x: Option<!> = None;
    println!("{}", x.is_none());
}
```

## Fixed

```rust
enum Never {}

fn main() {
    let x: Option<Never> = None;
    println!("{}", x.is_none());
}
```
