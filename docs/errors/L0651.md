# L0651: reference to a packed field

A field of a `repr(packed)` struct can sit at an unaligned address, so a
reference to it could be an unaligned reference. Rust rejects this, and so
does lust. Copy the field value out instead.

## Wrong

```rust
#[repr(packed)]
struct P {
    a: u8,
    b: u64,
}

fn main() {
    let p = P { a: 1, b: 2 };
    let r = &p.b;
    println!("{}", r);
}
```

## Fixed

```rust
#[repr(packed)]
struct P {
    a: u8,
    b: u64,
}

fn main() {
    let p = P { a: 1, b: 2 };
    let b = p.b;
    println!("{}", b);
}
```
