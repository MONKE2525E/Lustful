# L0705: lust cannot prove this dyn lifetime bound

<!-- rustc-wrong: pass -->

A `'static` object bound (`dyn Trait + 'static`, or the default
under `&'static dyn Trait`) needs the concrete type to live for
`'static`. lust erases lifetimes inside types, so it cannot check
that for a type that holds references, and it rejects the
coercion instead of guessing. Rust accepts the wrong example,
because the reference there is `'static`. Use a concrete type
without references, or drop the `'static` bound.

## Wrong

```rust
trait Tr {
    fn get(&self) -> u8;
}

impl Tr for &u8 {
    fn get(&self) -> u8 {
        **self
    }
}

static X: u8 = 5;

fn keep(d: &(dyn Tr + 'static)) -> u8 {
    d.get()
}

fn main() {
    let r: &'static u8 = &X;
    println!("{}", keep(&r));
}
```

## Fixed

```rust
trait Tr {
    fn get(&self) -> u8;
}

impl Tr for u8 {
    fn get(&self) -> u8 {
        *self
    }
}

static X: u8 = 5;

fn keep(d: &(dyn Tr + 'static)) -> u8 {
    d.get()
}

fn main() {
    println!("{}", keep(&X));
}
```
