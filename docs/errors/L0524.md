# L0524: attribute used wrongly

A built-in attribute lust accepts (`inline`, `repr`, `must_use`,
`deprecated`, `cold`, `test`, or a lint level) has a malformed input
or sits on a target Rust does not permit for it. Rust rejects both
shapes, so lust does too, instead of ignoring the attribute. Fix the
input to a documented form, or move the attribute to a target it
allows: `inline` on functions, `repr` on structs, enums, and unions.

## Wrong

```rust
#[inline]
struct S;

fn main() {
    let _s = S;
    println!("x");
}
```

## Fixed

```rust
struct S;

#[inline]
fn one() -> i32 {
    1
}

fn main() {
    let _s = S;
    println!("{}", one());
}
```
