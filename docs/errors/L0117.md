# L0117: recursive type has infinite size

A struct or enum contains itself by value, so a value of this type would need endless
memory. Put the recursive part inside a `Vec`, which stores its elements on the heap.
`Box` is not supported yet.

## Wrong

```rust
struct Node {
    next: Node,
    v: i64,
}

fn main() {
    println!("node");
}
```

## Fixed

```rust
struct Node {
    kids: Vec<Node>,
    v: i64,
}

fn main() {
    let n = Node { kids: Vec::new(), v: 1 };
    println!("{}", n.v);
}
```
