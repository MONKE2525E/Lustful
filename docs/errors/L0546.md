# L0546: mem::discriminant of a type that is not an enum

`std::mem::discriminant(&v)` gives an unspecified value when `v` is not
an enum. rustc denies this by default (lint `enum_intrinsics_non_enums`)
when the type is known at the call, so the call is an error unless an
`#[allow]`, `#[warn]`, or `#[expect]` of the lint covers it. lust reads
these levels on the statement and on the enclosing fn. A call in a
generic fn whose type is a type parameter is not checked.

## Wrong

```rust
struct S(u8);

fn main() {
    let d = std::mem::discriminant(&S(1));
    println!("{d:?}");
}
```

## Fixed

```rust
enum E {
    A(u8),
}

fn main() {
    let d = std::mem::discriminant(&E::A(1));
    println!("{d:?}");
}
```
