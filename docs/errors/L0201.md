# L0201: references in struct fields are not supported

A field cannot hold a reference such as `&str` or `&T`. Without lifetime names, the
compiler cannot prove that the referenced value outlives the struct. Store an owned
value (for example `String` instead of `&str`), or store an index and pass the
referenced value to each method.

## Wrong

```rust
struct Holder {
    name: &str,
}

fn main() {}
```

## Fixed

```rust
struct Holder {
    name: String,
}

fn main() {
    let h = Holder { name: String::from("a") };
    println!("{}", h.name);
}
```
