# L0201: a reference in a field needs a lifetime

A field that holds a reference must name its lifetime: a lifetime param of
the struct or enum (`struct Holder<'a> { name: &'a str }`) or `'static`.
An elided lifetime in a field is an error in Rust too (E0106). Declare a
lifetime on the type, use `'static`, or store an owned value.

## Wrong

```rust
struct Holder {
    name: &str,
}

fn main() {}
```

## Fixed

```rust
struct Holder {
    name: String,
}

fn main() {
    let h = Holder { name: String::from("a") };
    println!("{}", h.name);
}
```
