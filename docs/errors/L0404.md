# L0404: `unsafe` is not supported

<!-- rustc-wrong: pass -->

Lust has no `unsafe` blocks or functions. Raw pointers exist as address
values only: make them from references, compare and hash them, and read
their address, but do not dereference them. Remove the unsafe code
and use the safe subset instead: owned values, references, `Vec`, and indexes with
bounds checks. Rust accepts the wrong example; lust does not.

## Wrong

```rust
fn main() {
    let x = unsafe { 41 };
    println!("{}", x + 1);
}
```

## Fixed

```rust
fn main() {
    let x = { 41 };
    println!("{}", x + 1);
}
```
