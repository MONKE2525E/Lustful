# L0404: unsupported unsafe function or missing unsafe block

<!-- rustc-wrong: pass -->

Lust supports lexical unsafe blocks for scalar C imports, but does not support
unsafe Rust functions. Keep Rust functions safe and use an unsafe block at each
foreign call, upholding that function's safety requirements. General unsafe
operations, including raw-pointer dereference, remain unsupported.

Rust accepts the wrong example; Lust rejects its unsafe function declaration.

## Wrong

```rust
unsafe fn value() -> i32 { 41 }
fn main() { println!("{}", unsafe { value() } + 1); }
```

## Fixed

```rust
fn value() -> i32 { 41 }
fn main() { println!("{}", value() + 1); }
```
