# L0203: lifetime name or form not supported

<!-- rustc-wrong: pass -->

Two cases share this code. A lifetime name that the item does not
declare is an error in Rust too (E0261). The other case is a lifetime
form that lust does not check yet, so it rejects the program instead of
accepting a borrow rustc might reject: lifetimes in fn pointer types or
in a `dyn` type's trait arguments, an explicit lifetime in a body type
other than a `let` annotation on names, lifetime params on traits, and
`T: 'a` bounds on named lifetimes. Rust accepts the wrong example; lust
does not yet. Elide the lifetime, or use a generic `F: Fn(&T)` param.

## Wrong

```rust
fn apply(f: fn(&'static str) -> usize) -> usize {
    f("abc")
}

fn len(s: &str) -> usize {
    s.len()
}

fn main() {
    println!("{}", apply(len));
}
```

## Fixed

```rust
fn apply(f: fn(&str) -> usize) -> usize {
    f("abc")
}

fn len(s: &str) -> usize {
    s.len()
}

fn main() {
    println!("{}", apply(len));
}
```
