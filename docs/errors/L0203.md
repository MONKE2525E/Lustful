# L0203: lifetime syntax is not supported

<!-- rustc-wrong: pass -->

Lust rejects lifetime names such as `'a` on purpose. It uses Rust elision rules only:
a returned reference borrows from `self`, or from the only reference parameter. Remove
the lifetime names. If elision is ambiguous, return an owned value or an index. Rust
accepts the wrong example; lust does not.

## Wrong

```rust
fn id<'a>(x: &'a i64) -> &'a i64 {
    x
}

fn main() {
    println!("{}", id(&3));
}
```

## Fixed

```rust
fn id(x: &i64) -> &i64 {
    x
}

fn main() {
    println!("{}", id(&3));
}
```
