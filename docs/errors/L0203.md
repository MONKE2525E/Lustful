# L0203: lifetime name or form not supported

<!-- rustc-wrong: pass -->

Two cases share this code. A lifetime name that the item does not
declare is an error in Rust too (E0261). The other case is a lifetime
form that lust does not check yet, so it rejects the program instead of
accepting a borrow rustc might reject: an explicit lifetime in a type
annotation inside a body, lifetimes in fn pointer types or in a `dyn`
type's trait arguments, lifetime params on traits, and `T: 'a` bounds on
named lifetimes. Rust accepts the wrong example; lust does not yet.
Remove the annotation and let the type be inferred, or elide the lifetime.

## Wrong

```rust
fn first<'a>(x: &'a [i64]) -> i64 {
    let y: &'a i64 = &x[0];
    *y
}

fn main() {
    println!("{}", first(&[3, 4]));
}
```

## Fixed

```rust
fn first<'a>(x: &'a [i64]) -> i64 {
    let y = &x[0];
    *y
}

fn main() {
    println!("{}", first(&[3, 4]));
}
```
