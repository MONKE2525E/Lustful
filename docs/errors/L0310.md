# L0310: value used before it is assigned

On some path, the variable has no value yet at this use. Assign a value on every path
before the use, for example with an `else` branch or a starting value.

## Wrong

```rust
fn main() {
    let x: i64;
    if std::env::args().count() > 5 {
        x = 1;
    }
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x: i64;
    if std::env::args().count() > 5 {
        x = 1;
    } else {
        x = 0;
    }
    println!("{}", x);
}
```
