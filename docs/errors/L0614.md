# L0614: this trait or generic form is not supported yet

<!-- rustc-wrong: pass -->

Most trait and generic forms work. A few still do not:
generic parameter defaults and negative impls. The message
names the form. Write the parameter's type out at each use
instead of defaulting it. Rust accepts the wrong example;
lust does not.

## Wrong

```rust
struct Bag<T = i64> {
    v: T,
}

fn main() {
    let b = Bag { v: 3 };
    println!("{}", b.v);
}
```

## Fixed

```rust
struct Bag<T> {
    v: T,
}

fn main() {
    let b = Bag { v: 3 };
    println!("{}", b.v);
}
```
