# L0614: this trait or generic form is not supported yet

<!-- rustc-wrong: pass -->

Most trait and generic forms work. A few still do not:
generic parameter defaults that name a lifetime, written
higher-ranked (`for<'a>`) bounds, negative impls, and generic
fns named by a qualified path as values (`<W<u8>>::get`). The
message names the form. Write the defaulted type out at each
use instead. Rust accepts the wrong example; lust does not.

## Wrong

```rust
struct Pair<'a, T = &'a str> {
    first: T,
    second: &'a str,
}

fn main() {
    let p: Pair = Pair { first: "a", second: "b" };
    println!("{} {}", p.first, p.second);
}
```

## Fixed

```rust
struct Pair<'a, T> {
    first: T,
    second: &'a str,
}

fn main() {
    let p: Pair<&str> = Pair { first: "a", second: "b" };
    println!("{} {}", p.first, p.second);
}
```
