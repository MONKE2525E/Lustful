# L0614: traits and generics are not supported yet

<!-- rustc-wrong: pass -->

The AST has shapes for trait definitions and impls, generic parameters,
bounds, and `where` clauses, but the trait solver and monomorphizer do not
exist yet. The message names the form. Write one version per concrete type
for now. Rust accepts the wrong example; lust does not.

## Wrong

```rust
fn id<T>(x: T) -> T {
    x
}

fn main() {
    println!("{}", id(3));
}
```

## Fixed

```rust
fn id(x: i64) -> i64 {
    x
}

fn main() {
    println!("{}", id(3));
}
```
