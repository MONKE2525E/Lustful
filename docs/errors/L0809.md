# L0809: this macro form is not supported yet

<!-- rustc-wrong: pass -->

The macro is a known Rust macro, but lust has no support for it yet.
The wrong example is valid Rust; lust rejects it with this code rather
than guessing at its meaning.

## Wrong

```rust
struct Point {
    x: i64,
    y: i64,
}

fn main() {
    println!("{}", std::mem::offset_of!(Point, y));
}
```

## Fixed

```rust
fn main() {
    println!("hi");
}
```
