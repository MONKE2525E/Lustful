# L0809: this macro form is not supported yet

<!-- rustc-wrong: pass -->

The macro is a known Rust macro, but lust has no support for this form
of it yet. The wrong example is valid Rust; lust rejects it with this
code rather than guessing at its meaning.

## Wrong

```rust
fn main() {
    let _x = dbg!(1, 2);
}
```

## Fixed

```rust
fn main() {
    let _x = dbg!(1);
    let _y = dbg!(2);
}
```
