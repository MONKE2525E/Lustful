# L0105: wrong number of arguments

A call passes more or fewer arguments than the function takes. Pass exactly the declared
arguments, in order.

## Wrong

```rust
fn add(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    println!("{}", add(1));
}
```

## Fixed

```rust
fn add(a: i64, b: i64) -> i64 {
    a + b
}

fn main() {
    println!("{}", add(1, 2));
}
```
