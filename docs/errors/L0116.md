# L0116: invalid cast

This `as` cast is not allowed. Lust allows casts between integers, from `bool` and
`char` to integers, and from `u8` to `char`. For other conversions, use a method such
as `.len()` or `.to_string()`.

## Wrong

```rust
fn main() {
    let s = String::from("a");
    let n = s as i64;
    println!("{}", n);
}
```

## Fixed

```rust
fn main() {
    let s = String::from("a");
    let n = s.len() as i64;
    println!("{}", n);
}
```
