# L0002: name is not in Unicode normal form C (NFC)

<!-- rustc-wrong: pass -->

Rust treats two names that are equal after Unicode normalization
(NFC) as the same name. Lust interns names as written, so it
rejects a name that is not already in NFC form. Write the name
with precomposed characters, or use an ASCII name. The wrong
example writes the last letter as `e` plus a combining acute
accent (U+0301); the fixed example uses the precomposed
character (U+00E9).

## Wrong

```rust
fn main() {
    let café = 1;
    println!("{}", café);
}
```

## Fixed

```rust
fn main() {
    let café = 1;
    println!("{}", café);
}
```
