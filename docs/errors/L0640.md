# L0640: this std item is declared but not yet implemented

<!-- rustc-wrong: pass -->

Lust std declares the same surface as real std for the types and
modules it exposes. An item whose body does not exist yet gives this
code at the call site, naming the item. Rust accepts the wrong
example; lust does not. Use an item lust implements today, or write
the behavior in your own code.

## Wrong

```rust
fn main() {
    println!("about to abort");
    std::process::abort();
}
```

## Fixed

```rust
fn main() {
    println!("about to exit");
    std::process::exit(1);
}
```
