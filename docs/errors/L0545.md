# L0545: a codepoint that changes text direction

A raw Unicode codepoint that changes the visible direction of text
(U+202A to U+202E, U+2066 to U+2069) can make code read differently
from what the compiler sees. rustc denies it by default in comments
(lint `text_direction_codepoint_in_comment`) and in string literals,
char literals, and doc comments (`text_direction_codepoint_in_literal`).
rustc lifts these lints only by a crate-level `#![allow]`, which lust
does not read, so lust always rejects them. In a literal, write the
escape `\u{202E}` instead.

## Wrong

```rust
fn main() {
    println!("a‮b");
}
```

## Fixed

```rust
fn main() {
    println!("a\u{202e}b");
}
```
