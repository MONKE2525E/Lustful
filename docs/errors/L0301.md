# L0301: use of moved value

A value was moved to a new owner, and the old variable is used after the move. After a
move, the old variable holds nothing. Borrow the value with `&` if the other code only
reads it, or clone it with `.clone()` before the move if both sides need to own it.

## Wrong

```rust
fn take(s: String) -> usize {
    s.len()
}

fn main() {
    let s = String::from("x");
    take(s);
    println!("{}", s);
}
```

## Fixed

```rust
fn take(s: &String) -> usize {
    s.len()
}

fn main() {
    let s = String::from("x");
    take(&s);
    println!("{}", s);
}
```
