# L0502: ambiguous module file

`mod foo;` can name `foo.rs` or `foo/mod.rs`. When both files exist there
is no preference order, in Rust or in lust. Delete one of them.

## Files

### amb.rs

```rust
pub fn value() -> i64 {
    1
}
```

### amb/mod.rs

```rust
pub fn value() -> i64 {
    2
}
```

## Wrong

```rust
mod amb;

fn main() {
    println!("{}", amb::value());
}
```

## Fixed

```rust
fn main() {
    println!("{}", 1);
}
```
