# L0630: outside the bounded const evaluator

A const context used a form the bounded evaluator of docs/ARCH.md section
2.13 does not run, the evaluation hit the step limit, or the value could
not be computed (overflow, division by zero, a failed assert). Overflow
in a const is always an error; it never wraps.

## Wrong

```rust
const X: u8 = 200 + 100;

fn main() {
    println!("{}", X);
}
```

## Fixed

```rust
const X: u16 = 200 + 100;

fn main() {
    println!("{}", X);
}
```
