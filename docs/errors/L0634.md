# L0634: attempt to use a non-constant value in a constant

A const context names a local variable or parameter of the function
around it. An inline `const { .. }` block, an array repeat count, and
a const expression in a written type (an array length, a const
argument) are evaluated at compile time, apart from any one call, so
they cannot read a local. This holds in code that never runs too,
such as an `if false` branch (rustc E0435). Use a `const` item, or
compute the value outside the const context.

## Wrong

```rust
fn main() {
    let n = 2usize;
    let a = [0u8; { if false { n; } 3 }];
    println!("{}", a.len());
}
```

## Fixed

```rust
const N: usize = 2;

fn main() {
    let a = [0u8; { if false { N; } 3 }];
    println!("{}", a.len());
}
```
