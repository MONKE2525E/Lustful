# L0309: cannot assign through a shared reference

A shared `&` reference is read-only. To write through a reference, take a `&mut`
reference from a `let mut` variable.

## Wrong

```rust
fn main() {
    let x = 1;
    let r = &x;
    *r = 2;
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let mut x = 1;
    let r = &mut x;
    *r = 2;
    println!("{}", x);
}
```
