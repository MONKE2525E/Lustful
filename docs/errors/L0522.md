# L0522: this attribute is not supported yet

<!-- rustc-wrong: pass -->

Lust knows this attribute by name (`path`, `inline`, and kin)
but does not act on it yet, so it rejects it instead of ignoring it.
An attribute name lust does not know at all gives L0402 instead.
Remove the attribute. Rust accepts the wrong example; lust does not.
`cfg` on items is the exception: expansion evaluates it for the host
target and strips items that are off (see ARCH 6.1).

## Wrong

```rust
#[inline]
fn val() -> i64 {
    1
}

fn main() {
    println!("{}", val());
}
```

## Fixed

```rust
fn val() -> i64 {
    1
}

fn main() {
    println!("{}", val());
}
```
