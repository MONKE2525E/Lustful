# L0522: this attribute is not supported yet

<!-- rustc-wrong: pass -->

Lust knows this attribute by name (`path`, `track_caller`, and kin)
but does not act on it yet, so it rejects it instead of ignoring it.
An attribute name lust does not know at all gives L0402 instead.
Remove the attribute. Rust accepts the wrong example; lust does not.
`#![recursion_limit]` is honored from 128 up; a lower value is
rejected, because rustc also checks type, trait, and layout depth
against it, and lust does not track those.
`cfg` on items and `repr` are the exceptions: expansion evaluates
item `cfg` for the host target (see ARCH 6.1), and layout uses
`repr` (see ARCH 4.4). The advisory attributes `inline`, `cold`,
`must_use`, and `deprecated` are accepted and ignored (ARCH 1.6).

## Wrong

```rust
#[track_caller]
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
