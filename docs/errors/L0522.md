# L0522: this attribute is not supported yet

<!-- rustc-wrong: pass -->

Lust knows this attribute by name (`cfg`, `repr`, `path`, `inline`, and kin)
but does not act on it yet, so it rejects it instead of ignoring it. An
attribute name lust does not know at all gives L0402 instead. Remove the
attribute. Rust accepts the wrong example; lust does not.

## Wrong

```rust
#[cfg(unix)]
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
