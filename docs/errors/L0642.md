# L0642: intrinsics can only be called from lust's shipped library crates

Intrinsics under `core::intrinsics` are compiler-known calls reserved
for the standard library lust ships (core, alloc, std, and named
adapter crates, each for its own list). User crates cannot call them,
even by writing the same path. Real Rust also rejects an
`core::intrinsics` call like the wrong example. Call the public std
item that wraps the intrinsic instead.

## Wrong

```rust
fn main() {
    core::intrinsics::exit(1);
}
```

## Fixed

```rust
fn main() {
    std::process::exit(1);
}
```
