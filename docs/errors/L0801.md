# L0801: macro expansion hit a limit

Expansion steps are capped - depth 128, one million tokens per call,
sixteen million tokens per crate - so a runaway macro stops with this
error instead of hanging. Rust accepts some programs past the depth
cap only with `#![recursion_limit]`, which lust does not read yet.

## Wrong

```rust
macro_rules! m {
    () => {
        m!()
    };
}

fn main() {
    m!();
}
```

## Fixed

```rust
macro_rules! m {
    () => {
        1
    };
}

fn main() {
    println!("{}", m!());
}
```
