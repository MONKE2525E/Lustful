# L0801: macro expansion hit a limit

Expansion steps are capped - depth 128 (or the crate's
`#![recursion_limit = "N"]`), one million tokens per call, and
sixteen million tokens per crate - so a runaway macro stops with this
error instead of hanging.

## Wrong

```rust
macro_rules! m {
    () => {
        m!()
    };
}

fn main() {
    m!();
}
```

## Fixed

```rust
macro_rules! m {
    () => {
        1
    };
}

fn main() {
    println!("{}", m!());
}
```
