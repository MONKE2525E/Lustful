# L0801: macro expansion hit a limit

Expansion steps are capped - depth 128 (or the crate root's
`#![recursion_limit = "N"]`, at most 2048), one million tokens per
call, and sixteen million tokens per crate - so a runaway macro stops
with this error instead of hanging. As in rustc, a std macro such as
`println!` also counts the levels its own expansion uses (its inner
`format_args!`), so a call near the limit can fail where a user macro
call at the same depth does not.

## Wrong

```rust
macro_rules! m {
    () => {
        m!()
    };
}

fn main() {
    m!();
}
```

## Fixed

```rust
macro_rules! m {
    () => {
        1
    };
}

fn main() {
    println!("{}", m!());
}
```
