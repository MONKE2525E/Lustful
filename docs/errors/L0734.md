# L0734: lifetime mismatch with the trait method

An impl method's signature must fit the trait method it implements: it
may return a longer-lived reference than the trait promises (a
`'static` result where the trait borrows from `self`), but not a
shorter one, and it may not demand a longer-lived input. rustc reports
these as "`impl` item signature doesn't match `trait` item signature".

## Wrong

```rust
trait Read {
    fn get(&self) -> &'static str;
}

struct S(String);

impl Read for S {
    fn get(&self) -> &str {
        &self.0
    }
}

fn main() {
    let s = S(String::from("a"));
    println!("{}", s.get());
}
```

## Fixed

```rust
trait Read {
    fn get(&self) -> &str;
}

struct S(String);

impl Read for S {
    fn get(&self) -> &str {
        &self.0
    }
}

fn main() {
    let s = S(String::from("a"));
    println!("{}", s.get());
}
```
