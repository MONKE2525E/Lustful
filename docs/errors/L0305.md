# L0305: cannot move out of a reference, an index, or a `Drop` type

Moving a value out from behind `&` or out of `v[i]` would leave a hole that the owner
still thinks is filled. An index read names its container instead: moving out of an
array or slice element reports a non-copy array or slice (rustc's E0508), and moving
out of a `Vec` element reports an index of the `Vec` (E0507). The same rule applies to
moving a field out of a type that implements `Drop`: the destructor would later run on
a partly emptied value (this is rustc's E0509). Borrow the value with `&` instead, copy
it out with `.clone()`, or move an array element out with an array pattern.

## Wrong

```rust
fn first(v: &Vec<String>) -> String {
    let s = v[0];
    s
}

fn main() {
    println!("{}", first(&vec![String::from("a")]));
}
```

## Fixed

```rust
fn first(v: &Vec<String>) -> String {
    let s = v[0].clone();
    s
}

fn main() {
    println!("{}", first(&vec![String::from("a")]));
}
```
