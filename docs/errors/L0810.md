# L0810: unsupported foreign interface

<!-- rustc-wrong: pass -->

Lust supports module-level `unsafe extern "C"` imports with six integer types
and unit returns on Linux x86_64 GNU using TinyCC. Pointer parameters,
callbacks, variadics, exports, and other foreign interfaces remain unsupported.
See [the supported subset](../VERENU.md#scalar-c-imports).

Rust accepts the wrong example's pointer declaration; Lust rejects it.

## Wrong

```rust
unsafe extern "C" {
    fn free(pointer: *mut u8);
}

fn main() {
    println!("hi");
}
```

## Fixed

```rust
fn main() {
    println!("hi");
}
```
