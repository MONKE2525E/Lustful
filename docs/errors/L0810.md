# L0810: extern blocks are not supported yet

<!-- rustc-wrong: pass -->

`extern` blocks and foreign functions have AST shapes, but lust has no
foreign-function boundary yet. Call a Rust function in the supported subset
instead. Rust accepts the wrong example; lust does not.

## Wrong

```rust
unsafe extern "C" {
    fn abs(x: i32) -> i32;
}

fn main() {
    println!("hi");
}
```

## Fixed

```rust
fn main() {
    println!("hi");
}
```
