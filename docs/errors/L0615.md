# L0615: overlapping impls

Two impls can apply to the same trait reference, and no
where clause of either is provably false under the orphan
rule. Rust rejects the same pair. Remove one impl, or narrow
its types so they cannot both apply.

## Wrong

```rust
trait A {}
trait B {}
trait Tr {}

impl<T: A> Tr for T {}
impl<T: B> Tr for T {}

fn main() {}
```

## Fixed

```rust
trait A {}
trait Tr {}

impl<T: A> Tr for T {}

fn main() {}
```
