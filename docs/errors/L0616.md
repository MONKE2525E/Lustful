# L0616: an impl that the orphan rule forbids

Neither the trait nor a covering type in the Self type is
defined in this file, so this crate may not write the impl.
Another crate could write the same impl and the two would
conflict. Implement the trait for a local type, or define
the trait locally.

## Wrong

```rust
impl Clone for u8 {
    fn clone(&self) -> u8 {
        *self
    }
}

fn main() {}
```

## Fixed

```rust
#[derive(Clone)]
struct Mine(u8);

fn main() {
    let m = Mine(3).clone();
    println!("{}", m.0);
}
```
