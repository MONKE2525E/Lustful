# L0506: unresolved import

A `use` path names no item. Every segment must name a module or an item
that is visible from the importing module. Check the spelling and the
module path. A `std`, `core`, or `alloc` path that std 1.99 does not
have is L0506 too, even when the import is unused (rustc E0432), and
so is a glob of a std item that is not a module or enum, or `{self}`
of one that is not a module, enum, or trait. A glob of a module into
itself (`use self::*;` at module level) is L0506 as well.

## Wrong

```rust
use crate::nope::Thing;

fn main() {
    println!("{}", 1);
}
```

## Fixed

```rust
fn main() {
    println!("{}", 1);
}
```
