# L0401: this macro call has no expanded form yet

User macros (`macro_rules!`) and most built-in macros expand before the
parser runs. The format macros (`format_args!`, `println!`, `vec!`, and
their kin) stay parser forms, which exist only in expression position.
One of them in a type or pattern position has no expanded form; Rust
rejects it too.

## Wrong

```rust
fn main() {
    let x: format_args!("a") = 1;
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x: i32 = 1;
    println!("{}", x);
}
```
