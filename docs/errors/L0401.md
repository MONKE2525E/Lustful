# L0401: user macros are not supported

<!-- rustc-wrong: pass -->

Lust rejects `macro_rules!` definitions and calls to user macros on purpose. Only the
built-in macros work: `println!`, `print!`, `eprintln!`, `eprint!`, `format!`, `vec!`,
`panic!`, `assert!`, `assert_eq!`, `assert_ne!`, `todo!`, and `unreachable!`. Rewrite
the macro as a plain function. Rust accepts the wrong example; lust does not.

## Wrong

```rust
macro_rules! one {
    () => {
        1
    };
}

fn main() {
    println!("hi");
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
