# L0401: this macro call has no expanded form yet

<!-- rustc-wrong: pass -->

User macros (`macro_rules!`) and the built-in macros expand before the
parser runs. A macro call that still reaches the parser is a form lust
does not have yet: the wrong example is `format_args!`, whose
`Arguments` value has no type in the subset yet. Rust accepts the
wrong example; lust does not.

## Wrong

```rust
fn main() {
    let _a = format_args!("hi");
}
```

## Fixed

```rust
fn main() {
    let s = format!("hi");
    println!("{}", s);
}
```
