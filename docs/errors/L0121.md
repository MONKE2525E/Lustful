# L0121: invalid assignment target

The left-hand side of an assignment is not a place that can hold a value. Assign to a
variable, a field, an index, or `*reference`.

## Wrong

```rust
fn one() -> i64 {
    1
}

fn main() {
    one() = 2;
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    let mut x = one();
    x = 2;
    println!("{}", x);
}
```
