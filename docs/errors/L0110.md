# L0110: mismatched types

A value is used where a different type is required. Lust does not convert between types
by itself, except that `&String` can become `&str`. Change the value, change the
annotation, or convert with `as`, `.to_string()`, or a similar method.

## Wrong

```rust
fn main() {
    let x: i32 = "hi";
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x: i32 = 3;
    println!("{}", x);
}
```
