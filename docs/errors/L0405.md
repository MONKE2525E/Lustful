# L0405: `async` is not supported

<!-- rustc-wrong: pass -->

Lust has no async functions, futures, or executors. Write plain functions. For
concurrent work, split the program into processes. Rust accepts the wrong example;
lust does not.

## Wrong

```rust
async fn later() -> i64 {
    1
}

fn main() {}
```

## Fixed

```rust
fn later() -> i64 {
    1
}

fn main() {
    println!("{}", later());
}
```
