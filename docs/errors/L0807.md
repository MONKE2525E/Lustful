# L0807: this macro definition is not valid

The matcher or the expansion side breaks a definition rule: a
fragment followed by a token its follow set forbids, a metavariable
bound twice or used without being bound, or a repetition with no
variable at its own depth to drive it.

## Wrong

```rust
macro_rules! m {
    ($e:expr +) => {
        $e
    };
}

fn main() {}
```

## Fixed

```rust
macro_rules! m {
    ($e:expr) => {
        $e
    };
}

fn main() {
    println!("{}", m!(1));
}
```
