# L0503: module file not found

`mod foo;` loads `foo.rs` or `foo/mod.rs` from the module search
directory. Neither file exists. Create one of them, or point the `mod`
item at another file with `#[path = "..."]`.

## Wrong

```rust
mod missing_xyz;

fn main() {
    println!("{}", 1);
}
```

## Fixed

```rust
fn main() {
    println!("{}", 1);
}
```
