# L0652: unsupported layout form

<!-- rustc-wrong: pass -->

The layout engine only computes sizes for the supported-shape grammar of
docs/ARCH.md section 4.4. A form outside it, such as `repr(simd)` or a
user union, gets this code instead of a guessed size. Rewrite the type
with a supported repr. Rust accepts the wrong example; lust does not.

Types from lust adapter crates (docs/ARCH.md section 3.6) whose layout
is not the real crate's also get this code in `size_of`, `align_of`,
`size_of_val`, `offset_of!`, and const evaluation, also when they sit
inside another type by value. References, `Box`, and `Vec` of them
still answer.

## Wrong

```rust
#[repr(simd)]
struct V(u64, u64);

fn main() {
    let v = V(1, 2);
    println!("{}", v.0 + v.1);
}
```

## Fixed

```rust
struct V(u64, u64);

fn main() {
    let v = V(1, 2);
    println!("{}", v.0 + v.1);
}
```
