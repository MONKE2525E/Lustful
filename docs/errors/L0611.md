# L0611: trait selection overflow

Proving this bound needs the same bound again, without end.
Selection stops at its depth cap instead of looping. Break the
cycle in the impl's where clauses.

## Wrong

```rust
trait T {}

impl<X> T for Vec<X> where Vec<X>: T {}

fn need<X: T>() {}

fn main() {
    need::<Vec<u8>>();
}
```

## Fixed

```rust
trait T {}

impl<X> T for Vec<X> {}

fn need<X: T>() {}

fn main() {
    need::<Vec<u8>>();
}
```
