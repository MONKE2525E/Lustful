# L0650: `offset_of!` on a default-repr type

<!-- rustc-wrong: pass -->

Rust does not promise field offsets for a default-repr type, but a
program can print them, so lust rejects `offset_of!` there instead of
answering with its own field order. Give the type a repr that fixes
the layout. Rust accepts the wrong example; lust does not.

## Wrong

```rust
struct P {
    a: u8,
    b: u64,
}

fn main() {
    println!("{}", std::mem::offset_of!(P, b));
}
```

## Fixed

```rust
#[repr(C)]
struct P {
    a: u8,
    b: u64,
}

fn main() {
    println!("{}", std::mem::offset_of!(P, b));
}
```
