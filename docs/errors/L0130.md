# L0130: no `main` function

A build needs exactly one entry point: `fn main()`. `lust check` on its own does not
report this error. `lust build` and `rustc` both do. Add a `main` function that takes
no parameters and returns `()`.

## Wrong

```rust
fn helper() -> i64 {
    1
}
```

## Fixed

```rust
fn helper() -> i64 {
    1
}

fn main() {
    println!("{}", helper());
}
```
