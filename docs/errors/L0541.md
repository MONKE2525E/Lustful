# L0541: operation will panic at runtime

The operands are known at compile time, and the operation always
panics: a division or remainder by zero, `MIN / -1`, or an index that
is out of bounds for its array type. Rust rejects this code with the
deny-level `unconditional_panic` lint, so lust rejects it too. If the
panic is the point of the test, allow the lint with
`#[allow(unconditional_panic)]`.

## Wrong

```rust
fn main() {
    let a = [1, 2, 3];
    println!("{}", a[5]);
}
```

## Fixed

```rust
fn main() {
    let a = [1, 2, 3];
    println!("{}", a[2]);
}
```
