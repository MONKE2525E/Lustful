# L0520: unknown cfg name

<!-- rustc-wrong: pass -->

A `#[cfg(...)]` predicate names a cfg lust does not know. Rust treats an
unknown cfg as false with a warning. Lust rejects it: silently dropping a
module or an item would change the program. Declare the cfg in build
script output, or remove it.

## Wrong

```rust
#[cfg(frobnicate)]
fn helper() -> i64 {
    1
}

fn main() {
    println!("{}", 1);
}
```

## Fixed

```rust
fn helper() -> i64 {
    1
}

fn main() {
    println!("{}", helper());
}
```
