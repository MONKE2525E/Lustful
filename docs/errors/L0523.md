# L0523: unstable cfg predicate

A `cfg` predicate names a cfg that stable Rust gates behind a nightly
feature, such as `overflow_checks`, `target_thread_local`, `ub_checks`,
or `sanitize`. Rust rejects the predicate (E0658) in `#[cfg]`,
`#[cfg_attr]`, and `cfg!`, even inside `any` or `not`. Lust does the
same. Remove the predicate, or use a stable cfg such as
`debug_assertions`.

## Wrong

```rust
#[cfg(overflow_checks)]
fn which() -> i32 {
    1
}

fn main() {
    println!("{}", which());
}
```

## Fixed

```rust
#[cfg(debug_assertions)]
fn which() -> i32 {
    1
}

#[cfg(not(debug_assertions))]
fn which() -> i32 {
    2
}

fn main() {
    println!("{}", which());
}
```
