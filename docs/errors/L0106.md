# L0106: duplicate definition

The same name is defined twice in one place: two functions, two types, or one struct
field set twice in a literal. Remove one definition, or rename one of them.

## Wrong

```rust
struct P {
    x: i64,
}

fn main() {
    let p = P { x: 1, x: 2 };
    println!("{}", p.x);
}
```

## Fixed

```rust
struct P {
    x: i64,
}

fn main() {
    let p = P { x: 2 };
    println!("{}", p.x);
}
```
