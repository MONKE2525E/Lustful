# L0610: type annotations needed

Trait selection could not pick one answer at this point, and no
later type information fixes it. This is the same class as
rustc E0282 and E0283. Add a type annotation so one impl is
picked.

## Wrong

```rust
trait Tr {
    fn v() -> u8;
}

impl Tr for u8 {
    fn v() -> u8 {
        1
    }
}

fn get<T: Tr>() -> u8 {
    T::v()
}

fn main() {
    println!("{}", get());
}
```

## Fixed

```rust
trait Tr {
    fn v() -> u8;
}

impl Tr for u8 {
    fn v() -> u8 {
        1
    }
}

fn get<T: Tr>() -> u8 {
    T::v()
}

fn main() {
    println!("{}", get::<u8>());
}
```
