# L0202: lifetime elision is ambiguous

The function returns a reference, but Rust elision rules cannot say which input it
borrows from. That happens with two or more reference parameters and no `self`. Return
an owned value, or change the signature so the result borrows from `self` or from the
only reference parameter.

## Wrong

```rust
fn pick(a: &str, b: &str) -> &str {
    a
}

fn main() {
    println!("{}", pick("a", "b"));
}
```

## Fixed

```rust
fn pick(a: &str, b: &str) -> String {
    if b.is_empty() {
        a.to_string()
    } else {
        a.to_string()
    }
}

fn main() {
    println!("{}", pick("a", "b"));
}
```
