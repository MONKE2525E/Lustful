# L0115: match is not exhaustive

A `match` does not cover every possible value. Add arms for the missing cases, or add a
`_ => ...` arm at the end.

## Wrong

```rust
enum Dir {
    Up,
    Down,
    Left,
}

fn name(d: Dir) -> i32 {
    match d {
        Dir::Up => 1,
        Dir::Down => 2,
    }
}

fn main() {
    println!("{}", name(Dir::Left));
}
```

## Fixed

```rust
enum Dir {
    Up,
    Down,
    Left,
}

fn name(d: Dir) -> i32 {
    match d {
        Dir::Up => 1,
        Dir::Down => 2,
        Dir::Left => 3,
    }
}

fn main() {
    println!("{}", name(Dir::Left));
}
```
