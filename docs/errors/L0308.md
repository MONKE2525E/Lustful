# L0308: cannot borrow as mutable

A `&mut` borrow needs a variable declared with `let mut`, and data behind a shared `&`
reference cannot be borrowed as mutable at all. Add `mut` to the declaration, or take a
`&mut` reference from the owner.

## Wrong

```rust
fn main() {
    let v: Vec<i64> = Vec::new();
    v.push(1);
    println!("{}", v.len());
}
```

## Fixed

```rust
fn main() {
    let mut v: Vec<i64> = Vec::new();
    v.push(1);
    println!("{}", v.len());
}
```
