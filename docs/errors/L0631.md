# L0631: non-const call in a const context

A `const` or `static` initializer, an inline `const { }` block, or a
`const fn` body used a form that cannot run at compile time: a call
to a function that is not a `const fn`, a trait method or operator
through a non-const impl, a closure or function pointer call, a
`for` loop, the `?` operator, a non-const macro, or a value whose
destructor would run in the const context. This matches rustc
errors E0015 and E0493.

## Wrong

```rust
fn g() -> i32 {
    3
}

const fn h() -> i32 {
    g()
}

fn main() {
    println!("{}", h());
}
```

## Fixed

```rust
const fn g() -> i32 {
    3
}

const fn h() -> i32 {
    g()
}

fn main() {
    println!("{}", h());
}
```
