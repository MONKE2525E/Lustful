# L0631: non-const call in a const context

A `const` or `static` initializer called a function that is not a
`const fn`. The initializer must run at compile time, so every call in
it must be to a `const fn`. This matches rustc error E0015.

## Wrong

```rust
static S: String = String::from("x");

fn main() {
    println!("{}", S);
}
```

## Fixed

```rust
static S: &str = "x";

fn main() {
    println!("{}", S);
}
```
