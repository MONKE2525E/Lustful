# L0118: integer literal out of range

The literal does not fit in its integer type. Use a smaller value, or choose a wider
type such as `i64` or `u32`.

## Wrong

```rust
fn main() {
    let x: u8 = 300;
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x: u8 = 200;
    println!("{}", x);
}
```
