# L9001: feature is not supported yet

<!-- rustc-wrong: pass -->

This Rust feature is valid, but the lust subset does not have it yet. The message names
the feature. Many features give this code, among them generics, traits, closures,
tuples, arrays, modules, `const` items, floats, and the `?` operator. Run
`lust capabilities --json` for the full list of rejected features. Rewrite this part
with the supported subset. Rust accepts the wrong example; lust does not.

## Wrong

```rust
struct Pair(i64, i64);

fn main() {
    let p = Pair(1, 2);
    println!("{}", p.0);
}
```

## Fixed

```rust
struct Pair {
    a: i64,
    b: i64,
}

fn main() {
    let p = Pair { a: 1, b: 2 };
    println!("{}", p.a);
}
```
