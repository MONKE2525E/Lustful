# L0505: this module path form is not supported yet

Modules, imports, same-crate module paths, and paths into dependency
crates lust compiles from source (workspace and path dependencies)
work. What remains under this code: path forms the checker cannot
place, such as a path through a name that is not a module, a type, or
a dependency crate of this crate. A dependency with no lust source,
adapter, or shim form reports L0508 instead.

## Wrong

```rust
fn main() {
    other::thing::go();
}
```

## Fixed

```rust
fn go() {
    println!("go");
}

fn main() {
    go();
}
```
