# L0505: this module path form is not supported yet

Modules, imports, and same-crate module paths work. What remains under
this code: paths into other crates' items (cross-crate resolution is
later work), and long paths the checker cannot place. Keep the path
inside this crate, or use the supported std surface.

## Wrong

```rust
fn main() {
    other::thing::go();
}
```

## Fixed

```rust
fn go() {
    println!("go");
}

fn main() {
    go();
}
```
