# L0505: modules and module paths are not supported yet

<!-- rustc-wrong: pass -->

The AST has shapes for `mod` items, `use` trees, and module paths, but the
module parser and resolver do not exist yet. Keep the program in one file
with no module paths. Rust accepts the wrong example; lust does not.

## Wrong

```rust
mod inner {
    pub fn one() -> i64 {
        1
    }
}

fn main() {
    println!("{}", inner::one());
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
