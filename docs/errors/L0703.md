# L0703: this method cannot be called on a trait object

The method exists, but a `dyn` value cannot run it. A method with
`where Self: Sized` has no vtable entry, so rustc reports "the
method cannot be invoked on a trait object". A method that takes
`self` by value would move a value whose size is not known, which
is rustc E0161. Call the method on the concrete type, or through a
generic parameter.

## Wrong

```rust
trait Tr {
    fn get(&self) -> u8;
    fn dup(&self) -> Self
    where
        Self: Sized;
}

struct S(u8);

impl Tr for S {
    fn get(&self) -> u8 {
        self.0
    }
    fn dup(&self) -> Self {
        S(self.0)
    }
}

fn main() {
    let s = S(4);
    let d: &dyn Tr = &s;
    let c = d.dup();
    println!("{}", c.get());
}
```

## Fixed

```rust
trait Tr {
    fn get(&self) -> u8;
    fn dup(&self) -> Self
    where
        Self: Sized;
}

struct S(u8);

impl Tr for S {
    fn get(&self) -> u8 {
        self.0
    }
    fn dup(&self) -> Self {
        S(self.0)
    }
}

fn main() {
    let s = S(4);
    let c = s.dup();
    let d: &dyn Tr = &c;
    println!("{}", d.get());
}
```
