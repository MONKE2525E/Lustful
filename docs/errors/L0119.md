# L0119: lower range bound is greater than the upper bound

The range pattern is empty: its first bound is larger than its second bound, so it can
never match. Swap the bounds, or fix the values.

## Wrong

```rust
fn main() {
    let x: i64 = 3;
    match x {
        5..=1 => println!("empty"),
        _ => println!("other"),
    }
}
```

## Fixed

```rust
fn main() {
    let x: i64 = 3;
    match x {
        1..=5 => println!("in range"),
        _ => println!("other"),
    }
}
```
