# L0704: the dyn type implements this trait already

`dyn Trait` implements `Trait` and every supertrait of `Trait` by
itself: calls go through the vtable. A written impl of one of
those traits for the dyn type would overlap that. This is rustc
E0371. Remove the impl. To add methods to the dyn type, write an
inherent `impl dyn Trait { ... }` block.

## Wrong

```rust
trait Tr {
    fn get(&self) -> u8;
}

impl Tr for dyn Tr {
    fn get(&self) -> u8 {
        0
    }
}

fn main() {}
```

## Fixed

```rust
trait Tr {
    fn get(&self) -> u8;
}

impl dyn Tr {
    fn twice(&self) -> u8 {
        self.get() * 2
    }
}

struct S;

impl Tr for S {
    fn get(&self) -> u8 {
        2
    }
}

fn main() {
    let s = S;
    let d: &dyn Tr = &s;
    println!("{}", d.twice());
}
```
