# L0509: glob name whose binding depends on rustc's import order

This is a lust subset rule: the code may be valid Rust, but lust rejects
it on purpose.

When one item reaches a module through two or more glob imports with
different visibility, rustc keeps the widest one. lust does the same.
But rustc resolves imports in its own event order, and when the first
glob's source module changes its own binding later (its visibility grew
through another glob), rustc fetches the binding again through that
glob and drops the wider visibility. Which item an ambiguity carries on
to the next glob importer depends on that order too. lust does not copy
rustc's order. It computes every binding the name may end with, and it
rejects a path or an import whose answer differs between them: a
different item, private in one and visible in another, a possible
ambiguity, or no binding at all. A re-export (`pub use`) of a glob name
is rejected the same way when rustc's widest and narrowest bindings of
it give the re-export different visibility.

In the wrong example below, `geometry` gets `Square` through a public
glob and through the private glob of `prelude`, and `prelude`'s own
binding can still widen. rustc accepts this order, but in 16 of the 96
orders of these modules and imports it reports `Square` as private.

Fix: import the item explicitly. An explicit import wins over every
glob, so the order does not matter. Removing one of the overlapping glob
imports also works.

<!-- rustc-wrong: pass -->

## Wrong

```rust
mod shapes {
    pub struct Square;
    impl Square {
        pub fn sides() -> u32 {
            4
        }
    }
}

mod extra {
    pub use crate::shapes::*;
}

mod prelude {
    pub use crate::shapes::*;
    pub(crate) use crate::extra::*;
}

mod geometry {
    pub use crate::shapes::*;
    use crate::prelude::*;
}

fn main() {
    println!("{}", geometry::Square::sides());
}
```

## Fixed

```rust
mod shapes {
    pub struct Square;
    impl Square {
        pub fn sides() -> u32 {
            4
        }
    }
}

mod extra {
    pub use crate::shapes::*;
}

mod prelude {
    pub use crate::shapes::*;
    pub(crate) use crate::extra::*;
}

mod geometry {
    pub use crate::shapes::Square;
    use crate::prelude::*;
}

fn main() {
    println!("{}", geometry::Square::sides());
}
```
