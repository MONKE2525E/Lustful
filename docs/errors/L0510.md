# L0510: item is private

The name exists, but its visibility does not reach this module. Make the
item `pub(crate)` (the smallest widening that works), `pub`, or add a
public re-export. Lust never applies the widening for you: visibility
changes API surface.

## Wrong

```rust
mod inner {
    pub fn shown() -> i64 {
        hidden()
    }

    fn hidden() -> i64 {
        1
    }
}

fn main() {
    println!("{}", inner::hidden());
}
```

## Fixed

```rust
mod inner {
    pub fn shown() -> i64 {
        hidden()
    }

    fn hidden() -> i64 {
        1
    }
}

fn main() {
    println!("{}", inner::shown());
}
```
