# L0633: this constant cannot be used in a pattern

The pattern names a constant whose type is not structural: Rust
requires a constant used in a pattern to have a type that derives
`PartialEq` (so the comparison is structural, never a custom
`PartialEq` implementation). Derive `PartialEq` on the type, match
a field of the value, or compare in a match guard instead. A
`static` in a pattern is a separate error (L0110).

## Wrong

```rust
struct S {
    x: i64,
}

const A: S = S { x: 1 };

fn main() {
    match (S { x: 1 }) {
        A => println!("a"),
        _ => println!("other"),
    }
}
```

## Fixed

```rust
const MAX: i64 = 7;

fn main() {
    match 7 {
        MAX => println!("max"),
        _ => println!("other"),
    }
}
```
