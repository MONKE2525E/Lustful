# L0641: this literal or std form is not supported yet

<!-- rustc-wrong: pass -->

Float and byte literals, known std types lust does not have yet (such as
`HashMap` or `Box`), and format forms beyond `{}` and `{:?}` all give this
code. The message names the form. Rewrite it with the supported subset.
Rust accepts the wrong example; lust does not.

## Wrong

```rust
fn main() {
    let x = 1.5;
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x = 3;
    println!("{}", x / 2);
}
```
