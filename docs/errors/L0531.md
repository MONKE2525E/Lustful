# L0531: unsupported deny-level lint

<!-- rustc-wrong: pass -->
<!-- lust-args: --manifest-path {work}/l0531/Cargo.toml --bin l0531wrong -->

The manifest denies a rust lint that lust does not check. Rust would
reject code that triggers the lint, so accepting the crate could accept a
program rustc rejects. Lower the lint to warn for lust dev builds, or
build the crate with Cargo. `unsafe_code` at deny or forbid is fine:
lust rejects `unsafe` outright.

## Files

### l0531/Cargo.toml

[package]

[[bin]]
