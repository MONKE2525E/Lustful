# L0802: no macro with this name is in scope

Macro lookup found no definition for the call: the name is misspelled,
the `macro_rules!` definition comes after the call in the file (textual
scope), or the macro was never imported or exported.

## Wrong

```rust
fn main() {
    println!("{}", one!());
}
```

## Fixed

```rust
macro_rules! one {
    () => {
        1
    };
}

fn main() {
    println!("{}", one!());
}
```
