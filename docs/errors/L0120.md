# L0120: break or continue outside a loop

`break` and `continue` are only allowed inside `loop`, `while`, and `for`. A `break`
with a value is only allowed in `loop`. Move the statement into a loop, or remove it.

## Wrong

```rust
fn main() {
    break;
}
```

## Fixed

```rust
fn main() {
    loop {
        break;
    }
    println!("done");
}
```
