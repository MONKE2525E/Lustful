# L0304: two mutable borrows at the same time

At most one `&mut` reference to a value may be in use at a time. Finish using the first
`&mut` reference before you take the second one. A block can end the first borrow early.

## Wrong

```rust
fn main() {
    let mut s = String::new();
    let a = &mut s;
    let b = &mut s;
    a.push('x');
    b.push('y');
}
```

## Fixed

```rust
fn main() {
    let mut s = String::new();
    {
        let a = &mut s;
        a.push('x');
    }
    let b = &mut s;
    b.push('y');
    println!("{}", s);
}
```
