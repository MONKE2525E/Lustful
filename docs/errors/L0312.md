# L0312: cannot assign while borrowed

A value cannot be assigned while a reference to it is still in use. Finish using the
reference first. A block can end the borrow before the assignment.

## Wrong

```rust
fn main() {
    let mut x = 1;
    let r = &x;
    x = 2;
    println!("{} {}", r, x);
}
```

## Fixed

```rust
fn main() {
    let mut x = 1;
    {
        let r = &x;
        println!("{}", r);
    }
    x = 2;
    println!("{}", x);
}
```
