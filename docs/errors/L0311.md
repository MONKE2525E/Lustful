# L0311: cannot move a borrowed value

A value cannot move to a new owner while a reference to it is still in use. The
reference would point at memory the new owner controls. Stop using the reference
before the move, or clone the value with `.clone()`.

## Wrong

```rust
fn main() {
    let s = String::from("a");
    let r = &s;
    let t = s;
    println!("{} {}", r, t);
}
```

## Fixed

```rust
fn main() {
    let s = String::from("a");
    let r = &s;
    let t = s.clone();
    println!("{} {}", r, t);
}
```
