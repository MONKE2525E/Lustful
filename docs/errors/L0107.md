# L0107: missing field

A struct literal or a struct pattern does not mention every field. In a literal, set
every field. In a pattern, add the missing fields or end the pattern with `..`.

## Wrong

```rust
struct P {
    x: i64,
    y: i64,
}

fn main() {
    let p = P { x: 1 };
    println!("{}", p.x);
}
```

## Fixed

```rust
struct P {
    x: i64,
    y: i64,
}

fn main() {
    let p = P { x: 1, y: 2 };
    println!("{} {}", p.x, p.y);
}
```
