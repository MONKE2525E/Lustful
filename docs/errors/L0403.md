# L0403: cannot derive this trait

The name in `#[derive(...)]` is not a trait lust can derive, or the derive is not
valid. Lust can derive `Debug`, `Clone`, `Copy`, `PartialEq`, `Eq`, `PartialOrd`,
`Ord`, `Hash`, and `Default`. A derived `Default` on an enum needs exactly one
`#[default]` unit variant, as in Rust. Remove the name, or write the needed methods
by hand in an impl block.

## Wrong

```rust
#[derive(Frob)]
struct S {
    x: i64,
}

fn main() {
    let a = S { x: 1 };
    println!("{}", a.x);
}
```

## Fixed

```rust
#[derive(Clone)]
struct S {
    x: i64,
}

fn main() {
    let a = S { x: 1 };
    let b = a.clone();
    println!("{}", b.x);
}
```
