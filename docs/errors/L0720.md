# L0720: ambiguous method

More than one trait in scope gives this method name for the
receiver type, at the same receiver form. Name the trait with
a fully qualified call.

## Wrong

```rust
trait A {
    fn m(&self) -> u8;
}
trait B {
    fn m(&self) -> u8;
}

struct S;

impl A for S {
    fn m(&self) -> u8 {
        1
    }
}

impl B for S {
    fn m(&self) -> u8 {
        2
    }
}

fn main() {
    println!("{}", S.m());
}
```

## Fixed

```rust
trait A {
    fn m(&self) -> u8;
}
trait B {
    fn m(&self) -> u8;
}

struct S;

impl A for S {
    fn m(&self) -> u8 {
        1
    }
}

impl B for S {
    fn m(&self) -> u8 {
        2
    }
}

fn main() {
    println!("{}", <S as A>::m(&S));
}
```
