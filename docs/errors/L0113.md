# L0113: operator cannot be applied

This operator does not work on these operand types, or a `for` loop tries to iterate
over a value that is not iterable in the subset. Both operands must have the same type,
and the type must support the operator. To iterate, use a range, `&vec`, `&mut vec`, or
`s.chars()`.

## Wrong

```rust
fn main() {
    let x = "a" - "b";
    println!("{}", x);
}
```

## Fixed

```rust
fn main() {
    let x = 5 - 2;
    println!("{}", x);
}
```
