# L0735: closure is not general enough

A closure goes to a bound such as `F: Fn(&String)`. The bound writes the
reference, so the callee can pass a borrow of its own data, with any
lifetime. The closure has a fixed lifetime in that argument: the
parameter has no annotation and the closure has no expected signature
where it is written (a `let` closure), or the annotation names a
lifetime (`|x: &'a String|`). rustc reports the same programs as
"implementation of `Fn` is not general enough". Write the parameter
type with an elided lifetime (`|x: &String|`), or write the closure in
the call.

The same holds for a type param or a fn item passed on to another
generic fn: `F: Fn(&'a u8)` cannot serve `G: Fn(&u8)` (rustc E0277), nor
can `fn f<'e: 'e>(x: &'e u8)`, whose lifetime is early-bound. Write the
bound or the parameter with an elided lifetime.

## Wrong

```rust
fn apply<F: Fn(&String) -> usize>(f: F) -> usize {
    let s = String::from("ab");
    f(&s)
}

fn main() {
    let len = |x| {
        let s: &String = x;
        s.len()
    };
    println!("{}", apply(len));
}
```

## Fixed

```rust
fn apply<F: Fn(&String) -> usize>(f: F) -> usize {
    let s = String::from("ab");
    f(&s)
}

fn main() {
    let len = |x: &String| x.len();
    println!("{}", apply(len));
}
```
