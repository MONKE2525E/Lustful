# L0632: const generic forms are not supported yet

<!-- rustc-wrong: pass -->

Const generic arguments and parameters have AST shapes but no support
yet. Const items, static items, const functions, explicit enum
discriminants, and inline const blocks do work; see the const codes
next to this one in the registry. Rust accepts the wrong example;
lust does not.

## Wrong

```rust
fn show() {
    println!("show");
}

fn main() {
    show::<3>();
}
```

## Fixed

```rust
fn show() {
    println!("show");
}

fn main() {
    show();
}
```
