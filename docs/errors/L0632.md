# L0632: const and static items are not supported yet

<!-- rustc-wrong: pass -->

`const` and `static` items, `const` functions, const generic arguments,
explicit enum discriminants, and inline const blocks have AST shapes but no
const evaluator yet. Use a plain function that returns the value. Rust
accepts the wrong example; lust does not.

## Wrong

```rust
const ONE: i64 = 1;

fn main() {
    println!("{}", ONE);
}
```

## Fixed

```rust
fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```
