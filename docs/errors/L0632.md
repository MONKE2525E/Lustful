# L0632: const form is not supported yet

<!-- rustc-wrong: pass -->

Scalar `const` and `static` items work (literals, other consts, integer
arithmetic). This code covers the const forms outside that bounded
evaluator: `const` functions, const generic arguments, inline const
blocks, mutable statics, calls and aggregates in initializers, and
explicit enum discriminants. Use a plain function that returns the
value. Rust accepts the wrong example; lust does not.

## Wrong

```rust
const fn one() -> i64 {
    1
}

fn main() {
    println!("{}", one());
}
```

## Fixed

```rust
const ONE: i64 = 1;

fn main() {
    println!("{}", ONE);
}
```
