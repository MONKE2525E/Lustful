# L0632: this const form is not supported yet

Const generics, const items, and const evaluation work within
their documented bounds. Const functions in traits do not:
they are unstable in Rust and have no checker here. The
message names the form.

## Wrong

```rust
trait T {
    const fn v() -> u8;
}

fn main() {}
```

## Fixed

```rust
trait T {
    fn v() -> u8;
}

fn main() {}
```
