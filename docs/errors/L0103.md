# L0103: no such field

The code reads or sets a field that the struct or enum variant does not have. Check the
field name in the type definition.

## Wrong

```rust
struct P {
    x: i64,
}

fn main() {
    let p = P { x: 1 };
    println!("{}", p.y);
}
```

## Fixed

```rust
struct P {
    x: i64,
}

fn main() {
    let p = P { x: 1 };
    println!("{}", p.x);
}
```
