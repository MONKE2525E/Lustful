# L0122: `mut` binding under a reference

A pattern under a reference (for example after `match &value`) binds references with
default binding modes. Lust does not allow `mut` on such a binding, because it is
unclear which value would change. Remove `mut`, or match on the value instead of a
reference. Rust 2024 rejects the wrong example too ("cannot mutably bind by value
within an implicitly-borrowing pattern").

## Wrong

```rust
fn main() {
    let o = Some(1);
    match &o {
        Some(mut x) => println!("{}", x),
        None => {}
    }
}
```

## Fixed

```rust
fn main() {
    let o = Some(1);
    match &o {
        Some(x) => println!("{}", x),
        None => {}
    }
}
```
