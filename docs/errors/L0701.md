# L0701: trait object types are not supported yet

A `dyn Trait` type appears in the program. Lust does not
support trait objects yet, so the type is rejected where it is
written. Rust accepts the same type when the trait is dyn
compatible. Use a generic parameter or an enum instead.

## Wrong

```rust
trait T {
    fn v(&self) -> u8;
}

fn f(_x: &dyn T) {}

fn main() {}
```

## Fixed

```rust
trait T {
    fn v(&self) -> u8;
}

fn f<T2: T>(_x: &T2) {}

fn main() {}
```
