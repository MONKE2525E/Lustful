# L0701: the trait is not dyn compatible

A `dyn Trait` value calls its methods through a vtable, so every
method must work without knowing the concrete type. This is the
same class as rustc E0038. The message names the item that breaks
it: a method with its own generic type parameters, a method that
uses `Self` outside the receiver (as a return type, or in a
parameter, even behind `&`), a method with no `self` receiver, an
associated const, a `Self: Sized` bound on the trait, or a
supertrait that is not dyn compatible. A method with `where Self:
Sized` is left out of the vtable instead, so it does not count.

## Wrong

```rust
trait Shape {
    fn area(&self) -> u32;
    fn copy(&self) -> Self;
}

struct Sq(u32);

impl Shape for Sq {
    fn area(&self) -> u32 {
        self.0 * self.0
    }
    fn copy(&self) -> Self {
        Sq(self.0)
    }
}

fn main() {
    let s = Sq(3);
    let d: &dyn Shape = &s;
    println!("{}", d.area());
}
```

## Fixed

```rust
trait Shape {
    fn area(&self) -> u32;
    fn copy(&self) -> Self
    where
        Self: Sized;
}

struct Sq(u32);

impl Shape for Sq {
    fn area(&self) -> u32 {
        self.0 * self.0
    }
    fn copy(&self) -> Self {
        Sq(self.0)
    }
}

fn main() {
    let s = Sq(3);
    let d: &dyn Shape = &s;
    println!("{}", d.area());
}
```
