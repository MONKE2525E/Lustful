# L0111: type cannot be inferred

The compiler does not have enough information to pick a type. This is common for a
method call such as `.pow(2)` on an integer whose type is not fixed yet, or for a
variable whose type never becomes known. Add a type annotation or an integer suffix
such as `5i64`.

## Wrong

```rust
fn main() {
    let x = 5;
    println!("{}", x.pow(2));
}
```

## Fixed

```rust
fn main() {
    let x: i64 = 5;
    println!("{}", x.pow(2));
}
```
