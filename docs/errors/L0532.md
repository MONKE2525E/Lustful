# L0532: rustc host tools forbidden

<!-- rustc-wrong: pass -->
<!-- lust-args: --manifest-path {work}/l0532/Cargo.toml --bin l0532wrong -->

Lust forbids rustc host preparation by default. A single source file and a
single-package manifest without dependencies, build scripts, or proc-macro
targets can compile under this policy. Other Cargo graphs require host feature
resolution or build outputs and are rejected before those tools or their cached
outputs are used. Cargo metadata uses `--no-deps` in strict mode.

`--host-tools` or `LUST_HOST_TOOLS=1` explicitly permits host preparation.
Such a run is not rustc-free. The same opt-in is required for `check --rustc`
and the Cargo/rustc release path. Explicit-target release builds use Lust's C
backend, subject to the same manifest policy.

The fixed example below compiles as a standalone file, without the manifest.
Removing a manifest flag does not compile that package or its dependencies.
