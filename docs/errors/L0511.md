# L0511: visibility names no enclosing module

A restricted visibility must name the item's own module or a module
that encloses it. `pub(super)` needs a parent module, so it is an
error at the crate root. `pub(in path)` must start with `crate`,
`self`, or `super` and name an enclosing module. To reach the whole
crate, write `pub(crate)`.

## Wrong

```rust
mod shapes {
    pub(in crate::tools) fn area() -> i64 {
        4
    }
}

mod tools {}

fn main() {
    println!("hi");
}
```

## Fixed

```rust
mod shapes {
    pub(crate) fn area() -> i64 {
        4
    }
}

mod tools {}

fn main() {
    println!("{}", shapes::area());
}
```
