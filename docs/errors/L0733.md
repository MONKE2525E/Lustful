# L0733: lifetime may not live long enough

A borrow flows from one region of the signature into another that the
signature does not say it outlives. Typical causes: returning data that
borrows from one parameter where the return type borrows from another,
returning a parameter's borrow as `'static`, or storing one parameter's
borrow behind another parameter. rustc reports the same programs as
"lifetime may not live long enough". Return or store data that borrows
from the right parameter, or return an owned value.

## Wrong

```rust
fn get(v: &Vec<String>) -> &'static str {
    &v[0]
}

fn main() {
    let v = vec![String::from("a")];
    println!("{}", get(&v));
}
```

## Fixed

```rust
fn get(v: &Vec<String>) -> &str {
    &v[0]
}

fn main() {
    let v = vec![String::from("a")];
    println!("{}", get(&v));
}
```
