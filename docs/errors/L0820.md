# L0820: this syntax form is not supported yet

<!-- rustc-wrong: pass -->

Core expression, pattern, and statement forms that land later give this
code: closures as `dyn Fn` values,
patterns in function parameters, and traits, unions, and generic type
aliases inside function bodies, among others (an impl inside a function
body is supported). The message names the
form. Rewrite it with the supported subset. Rust accepts the wrong
example; lust does not.

## Wrong

```rust
fn main() {
    trait Twice {
        fn twice(&self) -> Self;
    }
    impl Twice for u32 {
        fn twice(&self) -> u32 {
            self * 2
        }
    }
    println!("{}", 3u32.twice());
}
```

## Fixed

```rust
trait Twice {
    fn twice(&self) -> Self;
}

impl Twice for u32 {
    fn twice(&self) -> u32 {
        self * 2
    }
}

fn main() {
    println!("{}", 3u32.twice());
}
```
