# L0820: this syntax form is not supported yet

<!-- rustc-wrong: pass -->

Core expression, pattern, and statement forms whose parsers land later give
this code: closures, tuples, array literals, tuple and slice and reference
patterns, labels, let-else and let chains, the `?` operator, struct update
syntax, tuple structs, and items inside function bodies, among others. The
message names the form. Rewrite it with the supported subset. Rust accepts
the wrong example; lust does not.

## Wrong

```rust
fn main() {
    let add_one = |x: i64| x + 1;
    println!("{}", add_one(2));
}
```

## Fixed

```rust
fn add_one(x: i64) -> i64 {
    x + 1
}

fn main() {
    println!("{}", add_one(2));
}
```
