# L0820: this syntax form is not supported yet

<!-- rustc-wrong: pass -->

Core expression, pattern, and statement forms that land later give this
code: capturing closures, patterns in closure and function parameters,
closures returning references, let-else, the `?` operator, and items other
than `use` inside function bodies, among others. The message names the
form. Rewrite it with the supported subset. Rust accepts the wrong
example; lust does not.

## Wrong

```rust
fn main() {
    let base = 10;
    let add_base = |x: i64| x + base;
    println!("{}", add_base(2));
}
```

## Fixed

```rust
fn add_base(x: i64, base: i64) -> i64 {
    x + base
}

fn main() {
    println!("{}", add_base(2, 10));
}
```
