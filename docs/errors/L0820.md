# L0820: this syntax form is not supported yet

<!-- rustc-wrong: pass -->

Core expression, pattern, and statement forms that land later give this
code: closures stored inside a struct, enum, `Option`, or `Vec`,
closures as fn pointers or `dyn Fn` values,
patterns in function parameters, and items other than `use` inside
function bodies, among others. The message names the
form. Rewrite it with the supported subset. Rust accepts the wrong
example; lust does not.

## Wrong

```rust
fn main() {
    let add = |x: i32| x + 1;
    let maybe = Some(add);
    if let Some(f) = maybe {
        println!("{}", f(1));
    }
}
```

## Fixed

```rust
fn main() {
    let add = |x: i32| x + 1;
    println!("{}", add(1));
}
```
